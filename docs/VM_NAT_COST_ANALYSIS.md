## ✅ 비용 최적화 체크리스트

### 현재 설정이 무료인 이유

- [x] e2-micro는 Always Free 한도 내 (월 730시간)
- [x] 정적 IP가 VM에 할당되어 있음 (IN_USE 상태)
- [x] VM을 항시 실행 중 (과금 발생 안 함)
- [x] OS 이미지는 공식 Debian (무료)
- [x] 추가 과금 리소스 없음

### 과금 회피 방법

1. **절대 하면 안 되는 것:**
   - ❌ VM을 중지/삭제 → 정적 IP 미사용 상태 → $13/월 과금
   - ❌ 정적 IP 예약 후 VM 할당 안 함 → 즉시 과금
   - ❌ 프리미엄 네트워크 티어 사용 (PREMIUM 이미 선택됨)

2. **반드시 해야 할 것:**
   - ✅ VM을 항상 RUNNING 상태로 유지
   - ✅ 정적 IP를 VM에 할당 상태로 유지
   - ✅ e2-micro 사양 유지

## 📌 주의사항 및 권장사항
