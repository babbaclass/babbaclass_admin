## 시스템 개요

### 🎯 시스템 목적

바빠 스마트 클래스 정산 시스템은 본사, 지사, 원장 간의 **효율적인 정산 프로세스**를 자동화하고 관리하기 위한 웹 기반 시스템입니다.

### 👥 사용자 역할

| 역할 | 권한 | 접근 기능 |
|------|------|---------|
| **본사 관리자** (role_id=1) | 최고 권한 | 모든 기능 + 회원 관리 |
| **지사장** (role_id=2) | 중간 권한 | 소속 지사 정산 데이터 조회 |
| **원장/강사** (role_id=3) | 사용자 권한 | 개인 정산서 조회 및 확인 |

### 🔐 접속 환경

- **접속 URL:** 시스템 관리자가 제공하는 주소
- **브라우저:** Chrome, Firefox, Safari, Edge (최신 버전)
- **필수 정보:** 로그인 ID, 비밀번호

## 로그인 및 기본 설정

### 1️⃣ 로그인 절차

#### 단계 1: 로그인 페이지 접속
1. 브라우저 주소창에 시스템 URL 입력


3. 새 비밀번호 입력 및 확인

- **최소 길이:** 8자 이상
- **포함 요소:** 영문, 숫자, 특수문자 권장
- **예:** Babba@2025!

### 3️⃣ 세션 타임아웃

- **타임아웃 시간:** 30분 (비활성 상태)

## 정산 개요

### 📈 월별 정산 데이터 조회

#### 화면 설명

**정산 개요** 페이지에서는 선택한 지사의 월별 정산 현황을 표형식으로 조회합니다.

#### 필터링

1. **연도 선택 드롭다운**
   - 상단 우측의 드롭다운에서 연도 선택
   - 예: 2025, 2024, 2023

#### 표 컬럼 설명

| 컬럼 | 설명 | 단위 |
|------|------|------|
| **정산일** | 정산이 발생한 날짜 | YYYY-MM-DD |
| **판매 총액** | 전체 상품 판매 금액 | 원 (₩) |
| **사용된 적립금 총액** | 고객이 사용한 포인트/적립금 | 원 (₩) |
| **결제 총액** | 실제 결제된 금액 | 원 (₩) |
| **정산예정금액** | 정산 대상이 되는 금액 | 원 (₩) |
| **지급총액(공제전)** | 세금 공제 전 지급액 | 원 (₩) |

#### 데이터 해석 예시

```
날짜          판매총액    적립금사용    결제총액    정산예정    지급총액
2025-12-20   1,000,000     50,000      950,000    950,000     920,450
             (100%)        (5.3%)      (94.7%)    정산대상     세금공제
```

## 정산 현황

### 🔄 실시간 정산 진행 상황

정산 현황 페이지에서는 **각 원장별로 실시간 정산 데이터**를 모니터링합니다.

#### 필터링

1. **월 선택 드롭다운**
   - "전체" 또는 특정 월 (예: 2025-12) 선택
   - 선택된 월의 데이터만 표시

#### 표 컬럼 설명

| 컬럼 | 설명 | 예시 |
|------|------|------|
| **No** | 순번 | 1, 2, 3... |
| **Name** | 원장 이름 | 김원장 |
| **Nick** | 원장 닉네임 | kwon001 |
| **소비자가 총액** | 상품 정가 합계 | 1,500,000 |
| **판매가 총액** | 할인 후 판매 금액 | 1,200,000 |
| **배송비 총액** | 배송료 합계 | 50,000 |
| **사용된 적립금 총액** | 고객 적립금 사용액 | 100,000 |
| **실결제총액** | 최종 결제액 | 1,150,000 |

#### 데이터 활용

- **월별 비교:** 드롭다운으로 다른 월 선택하여 비교
- **원장별 성과:** 각 원장의 실결제 총액으로 실적 파악
- **정산 준비:** 월말에 정산 계산 전 현황 확인

## 정산서 조회 및 확인

### 📄 정산서란?

정산서는 **월별로 자동 생성되는 공식 문서**로, 정산 대상금액과 수수료율, 최종 지급액을 명시합니다.

### 1️⃣ 정산서 목록 보기

#### 정산서 페이지 접속

1. 원하는 지사의 "정산서" 버튼 클릭
2. 정산서 목록 페이지로 이동

#### 화면 구성

```
2025년
┌────────────────────────────┐
│ [1월]  [2월]  [3월] ...    │
└────────────────────────────┘

2024년
┌────────────────────────────┐
│ [1월]  [2월]  [3월] ...    │
└────────────────────────────┘
```

#### 월별 정산서 선택

- 원하는 연도와 월의 버튼 클릭
- 해당 월 정산서 상세 조회 페이지로 이동

### 2️⃣ 정산서 상세 조회

#### 정산자 정보

```
┌─────────────────────────────┐
│ 정산연월   │ 2025년 12월    │
│ 지사코드   │ 001            │
│ 은행       │ 국민은행       │
└─────────────────────────────┘

┌─────────────────────────────┐
│ 지사장명   │ 김관리         │
│ 지역       │ 본사 직영      │
│ 계좌번호   │ 123-456-7890  │
└─────────────────────────────┘
```

#### 정산 내역 테이블

| 수수료발생일 | 결제종류 | 코드 | 결제자 | 정산대상금액 | 수수료율 | 정산액 |
|-------------|--------|------|-------|------------|---------|--------|
| 2025-12-01 | 교재판매 | 001  | 홍길동 | 100,000   | 25%    | 25,000 |
| 2025-12-05 | 쿠폰    | 002  | 김영희 | 50,000    | 15%    | 7,500  |
| **소계**    | -      | -    | -     | **150,000** | -      | **32,500** |

#### 정산금 계산

```
총 합계:          32,500원
소득세 (3%):      975원
지방세 (0.3%):    97원
공제 후 지급액:   31,428원
```

#### 정산서 확인

1. 정산 내역 확인 후
2. 하단의 **"정산서를 확인하였습니다"** 버튼 클릭
3. 정산서 상태가 "확인됨"으로 변경
4. 지급 처리로 진행

### 3️⃣ 정산서 확인 상태

| 상태 | 의미 | 조치 |
|------|------|------|
| **DRAFT** | 작성 중 | 아직 발행되지 않음 |
| **ISSUED** | 발행됨 | 확인 필요 |
| **CONFIRMED** | 확인됨 | 지급 처리 예정 |
| **PAID** | 지급됨 | 완료 |

## 소속 원장 관리

### 👨‍🏫 원장 리스트 조회

#### 화면 설명

**소속 원장 리스트** 페이지에서는 지사에 소속된 모든 원장 정보를 조회합니다.

#### 필터링

1. **정렬 드롭다운**
   - "전체" (기본)
   - "이름순" 정렬
   - "가입일순" 정렬
   - "구매건순" 정렬

#### 표 컬럼 설명

| 컬럼 | 설명 | 예시 |
|------|------|------|
| **No** | 순번 | 1, 2, 3... |
| **이름** | 원장 성명 | 김원장 |
| **가입일** | 계약일 | 2024-01-15 |
| **아이디** | 로그인 ID | kwon001 |
| **연락처** | 휴대폰 | 010-1234-5678 |
| **이메일** | 이메일 주소 | kwon@example.com |
| **최근 6개월 구매** | 최근 180일 구매 건수 | 45 |

#### 데이터 활용

- **신입 원장 확인:** 가입일순 정렬로 최근 가입자 확인
- **활동 원장 확인:** 구매건순 정렬로 판매 현황 파악
- **연락 필요:** 연락처/이메일로 원장과 소통

## 회원 관리

### 👤 사용자 생성 (본사 관리자용)

#### 접근 권한

- **본사 관리자(role_id=1)만** 접근 가능
- 좌측 메뉴에서 "회원 관리" 클릭

#### 사용자 생성 절차

##### 1단계: 신규 사용자 추가 버튼 클릭
- "신규 추가" 또는 "Add" 버튼 클릭

##### 2단계: 기본 정보 입력

```

├─ 이름: [사용자 성명]
├─ 로그인 ID: [중복 없는 ID]
├─ 이메일: [이메일 주소]
├─ 회사: [소속 회사 선택]
└─ 역할: [역할 선택]
   ├─ 1 = 본사 관리자
   ├─ 2 = 지사장
   └─ 3 = 원장/강사
```

##### 3단계: 추가 정보 입력

```
선택 정보:
├─ 코드: [사용자 코드]
├─ 연락처: [휴대폰 번호]
├─ 은행명: [은행 이름]
├─ 계좌번호: [계좌 번호]
├─ 주소: [주소]
└─ 가입일: [계약일]
```

##### 4단계: 저장
- "저장" 또는 "Save" 버튼 클릭
- 사용자 생성 완료
- **기본 비밀번호 자동 생성**

| 역할 | 기본 비밀번호 |
|------|-----------|
| 본사 관리자 (1) | admin123 |
| 지사장 (2) | admin123 |
| 원장/강사 (3) | babba1234 |

> ⚠️ **주의:** 초기 로그인 후 반드시 비밀번호를 변경하도록 안내하세요.

## 자주 묻는 질문 (FAQ)

### Q1: 비밀번호를 잊어버렸어요.

**A:** 시스템 관리자에게 문의하면 임시 비밀번호를 재설정해드립니다.

### Q2: 정산서를 확인했는데 수정할 수 있나요?

**A:** 정산서는 자동 생성되는 문서로 사용자가 직접 수정할 수 없습니다. 오류가 있으면 관리자에게 문의하세요.

### Q3: 지급 계좌를 변경하고 싶어요.

**A:** 회원 관리에서 본인의 계좌 정보를 수정하거나, 지사장/관리자에게 요청하세요.

### Q4: 정산서가 발행되지 않았어요.

**A:** 다음을 확인하세요:
- 해당 월에 판매 기록이 있는가?
- 결제가 완료되었는가?
- 월말 정산 집계가 완료되었는가?

### Q5: 여러 지사의 정산 데이터를 동시에 볼 수 있나요?

**A:** 본사 관리자는 홈 대시보드에서 모든 지사를 볼 수 있습니다. 지사장은 해당 지사의 데이터만 조회 가능합니다.

### Q6: 원장별 정산 데이터는 어디서 보나요?

**A:** 
- **원장 본인:** 정산서 메뉴에서 자신의 정산서 조회
- **지사장/관리자:** 정산 개요, 정산 현황, 소속 원장 메뉴에서 조회

### Q7: 월별 정산이 언제 이루어지나요?

**A:** 매월 말일에 자동으로 정산이 집계되며, 정산서는 다음 달 초에 발행됩니다.

### Q8: 세금이 자동으로 계산되나요?

**A:** 네, 모든 세금(소득세 3%, 지방세 0.3%)은 자동으로 계산되고 공제됩니다.

### Q9: 정산서를 인쇄할 수 있나요?

**A:** 네, 정산서 페이지에서 브라우저의 인쇄 기능(Ctrl+P 또는 Cmd+P)을 사용하여 PDF로 저장하거나 인쇄할 수 있습니다.

### Q10: 시스템이 느려요. 어떻게 하나요?

**A:**
1. 브라우저 캐시 삭제
2. 인터넷 연결 확인
3. 다른 브라우저 시도
4. 여전히 문제면 관리자에게 문의

---

## 문제 해결

### 🔴 로그인이 안 돼요

#### 확인 사항

1. **ID/비밀번호 재확인**
   - 대문자/소문자 구분
   - 공백 확인

2. **CAPS LOCK 확인**
   - 키보드 CAPS LOCK 상태 확인

3. **브라우저 캐시 삭제**
   - 브라우저 개발자 도구 (F12)
   - 캐시 및 쿠키 삭제
   - 페이지 새로고침

4. **다른 기기/브라우저 시도**

5. **시스템 상태 확인**
   - 관리자에게 시스템 상태 문의

### 🔴 데이터가 안 보여요

#### 확인 사항

1. **권한 확인**
   - 접근 가능한 역할인가?

2. **필터 설정 확인**
   - 잘못된 필터가 설정되었나?
   - 필터 초기화 후 재조회

3. **날짜 범위 확인**
   - 선택한 연도/월에 데이터가 있나?

4. **페이지 새로고침**
   - F5 또는 브라우저 새로고침 버튼

5. **관리자에게 문의**

### 🔴 정산서가 보이지 않아요

#### 확인 사항

1. **월 선택 확인**
   - 올바른 연도/월을 선택했나?

2. **정산 여부 확인**
   - 해당 월에 판매 기록이 있나?
   - 월말 정산이 완료되었나?

3. **권한 확인**
   - 정산서 조회 권한이 있나?
   - 정산서를 조회할 수 있는 지사/원장인가?
