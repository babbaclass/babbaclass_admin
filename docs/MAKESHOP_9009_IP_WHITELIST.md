# Makeshop API 오류 9009 해결 방법

**문제**: return_code 9009 - 허가된 IP가 아님
**원인**: Makeshop에 API 호출 IP 화이트리스트 미등록

---

## 🔴 오류 분석

### 오류 코드: 9009
```
의미: 허가된 IP가 아닙니다 (IP not authorized)
원인: Makeshop 관리자 설정에서 이 IP 주소를 허용하지 않음
```

### 현재 아키텍처에서의 API 호출 IP

```
┌─────────────────────────────────────────┐
│  Cloud Run (babba-api)                  │
│  - 내부: 10.8.x.x (VPC Connector)      │
│  - 외부: 동적 (매번 다름)              │
└──────────┬──────────────────────────────┘
           │
           ↓ (VPC Connector를 통해 외부 연결)
           │
┌──────────▼──────────────────────────────┐
│  NAT VM (babba-nat-vm)                  │
│  - 내부: 10.178.0.2                    │
│  - 외부: 34.50.26.124 (고정) ← 이 IP!  │
└──────────┬──────────────────────────────┘
           │
           ↓
┌──────────▼──────────────────────────────┐
│  Makeshop API                           │
│  (이 IP를 화이트리스트에 등록해야 함)   │
└─────────────────────────────────────────┘
```

**Makeshop이 보는 발신 IP**: **34.50.26.124**

## ✅ 해결 방법

### 1단계: Makeshop 관리자 페이지 접속

1. Makeshop 관리자 페이지 로그인
2. "개발자 설정" 또는 "API 관리" 메뉴 찾기
3. "API 호출 IP 화이트리스트" 또는 "허용 IP" 설정 찾기

### 2단계: 고정 IP 등록

**등록할 IP 주소:**
```
34.50.26.124
```

**IP 정보:**
- 할당처: babba-nat-vm (e2-micro)
- 리전: asia-northeast3
- 상태: 고정 (정적)

### 3단계: 설정 저장 및 테스트

1. Makeshop 관리자 페이지에서 저장
2. 설정 적용 대기 (보통 1-5분)
3. API 테스트 재실행

## 🔍 추가 정보

### 왜 NAT VM을 통하는가?

```
이유: Makeshop API는 고정 IP 호출을 요구할 수 있음
- Cloud Run은 동적 IP 사용
- NAT VM은 고정 IP를 제공
- 고정 IP로 화이트리스트 등록 가능
```

### 현재 설정의 장점

✅ 비용 효율적 (e2-micro VM)
✅ 고정 IP 제공
✅ VPC 네트워크 격리
✅ Cloud SQL 보안 연결
