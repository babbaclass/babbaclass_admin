## 🟢 db-f1-micro 가능 기능

### ✅ 지원 기능

```
✅ 기본 CRUD 작업
✅ 자동 백업 (7일)

✅ SSL 암호화
✅ 클라우드 SQL 프록시

```


**결론**: 소규모/중규모 프로젝트에 완벽하지만, 엔터프라이즈 기능이 필요하면 상위 에디션 필요

## 🟢 해결책 3가지

### 옵션 1: 새 프로젝트 생성 (권장) ⭐

**가장 경제적인 방법**

```bash
# 새 프로젝트 생성
gcloud projects create babba-api-micro --display-name="Babba API - Micro"

# Standard 에디션 선택 가능
gcloud sql instances create babba-db \
  --database-version=MYSQL_8_0_41 \
  --region=asia-northeast3 \
  --tier=db-f1-micro \
  --edition=STANDARD \
  --project=babba-api-micro

# 비용: $12.50/월 (온디맨드)
```

**장점:**
- 최저 비용 ($12.50/월)
- 제약 없음
- 로컬 환경과 거의 동일한 성능

**단점:**
- 새 프로젝트 관리 필요
- 청구 계정 분리

---

### 옵션 2: 조직 정책 변경 요청

**IT 관리팀에 요청:**

```
현황: 현재 프로젝트는 ENTERPRISE_PLUS 강제
요청: Standard, Enterprise, Enterprise Plus 모두 사용 가능하도록 변경
사유: 개발/테스트 환경에서 비용 절감 필요
예상 절감: $215/월 → $12.50/월 (약 94% 절감)
```

**장점:**
- 기존 프로젝트 유지
- 최저 비용 가능

**단점:**
- IT 승인 대기
- 정책 변경 리스크

### 📋 구현 단계

**1단계: 새 프로젝트 생성**
```bash
gcloud projects create babba-api-micro \
  --display-name="Babba API - Micro Edition"

# 프로젝트 ID 메모: babba-api-micro
```

**2단계: 청billing 계정 연결**
```bash
gcloud billing projects link babba-api-micro \
  --billing-account=BILLING_ACCOUNT_ID
```

**3단계: Cloud SQL 인스턴스 생성**
```bash
gcloud sql instances create babba-db \
  --database-version=MYSQL_8_0_41 \
  --region=asia-northeast3 \
  --tier=db-f1-micro \
  --edition=STANDARD \
  --project=babba-api-micro
```

**4단계: 데이터베이스 및 사용자 생성**
```bash
gcloud sql databases create babba \
  --instance=babba-db \
  --project=babba-api-micro

gcloud sql users create babba_user \
  --instance=babba-db \
  --password=Fulfilled07!@ \
  --project=babba-api-micro
```

**5단계: Cloud Run 배포 (새 프로젝트)**
```bash
gcloud run deploy babba-api \
  --image=asia-northeast3-docker.pkg.dev/babba-api-micro/babba-registry/babba-api:latest \
  --region=asia-northeast3 \
  --set-env-vars=CLOUD_SQL_INSTANCE=babba-api-micro:asia-northeast3:babba-db,DB_NAME=babba,DB_USER=babba_user,DB_PASSWORD=Fulfilled07!@ \
  --project=babba-api-micro
```

## 💡 비용 절감 팁

1. **약정 할인 활용**
   - 1년: 25% 절감
   - 3년: 55% 절감

2. **자동 스토리지 증설 비활성화**

   - 예상치 못한 비용 증가 방지

3. **백업 관리**
   - 기본 7일 보관
   - 추가 보관 필요 시만 증설

4. **모니터링 활용**
   - 스토리지 사용량 추적
   - 필요 시 다운사이징
