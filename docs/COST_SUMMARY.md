## 💡 비용 정보

### db-f1-micro 스펙

- **vCPU**: 0.6개 (공유)
- **메모리**: 614MB (공유)
- **적합 용도**: 개발, 테스트, 소규모 프로덕션
- **최대 동시 연결**: ~100개

### 특징

✅ **가장 저렴함** - Standard 에디션 최저 사양  
✅ **충분한 성능** - 소규모 애플리케이션  
✅ **낮은 비용** - 월 $12.50만으로 운영 가능  
⚠️ **제한사항** - Enterprise 기능 없음 (읽기 복제본, HA 등)

## 🚀 추천 구성

**개발/테스트/소규모 프로덕션:**

```bash
# 현재 구성 (Enterprise - 프로젝트 제약)
gcloud sql instances list --project=astute-window-472313-g9
# 결과: babba-db (Enterprise Plus 강제)

# Standard 에디션이 필요한 경우 (새 프로젝트 권장)
gcloud sql instances create babba-db-std \
  --database-version=MYSQL_8_0_41 \
  --region=asia-northeast3 \
  --tier=db-f1-micro \
  --project=astute-window-472313-g9

# 월간 비용: $12.50 (온디맨드)
```

## 📋 현재 프로젝트 상황

**⚠️ 주의**: 귀사 프로젝트는 **ENTERPRISE_PLUS Edition 강제**

- ❌ db-f1-micro 사용 불가능 (현재 프로젝트)
- ❌ Standard 에디션으로 변경 불가능 (조직 정책)
- ✅ Enterprise/Enterprise Plus만 가능 (db-perf-optimized-N-2 최소)

**해결책:**
1. **새 프로젝트 생성** (Standard 에디션 선택)
2. **IT에 조직 정책 변경 요청**
3. **현재 프로젝트로 계속** (Enterprise Plus 사용)
