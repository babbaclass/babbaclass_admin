# Cloud SQL db-f1-micro 상세 비용 분석

## 🎯 개요

이 문서는 **Standard 에디션 db-f1-micro**의 정확한 월간 비용을 **시간 단위**로 계산합니다.

**결과:**
```
기본 구성: $12.63/월 (약 $12.50 올림)
온디맨드: 무할인
약정할인: 25% ~ 55% 가능
```

---

## 💰 세부 계산

### 1️⃣ 인스턴스 비용 (db-f1-micro)

#### GCP 공식 가격

**asia-northeast3 (Seoul) 기준:**
```
$0.0145/시간 (온디맨드 가격)
```

**월간 시간 계산:**
```
1개월 = 30일 × 24시간 = 720시간

(또는 정확하게: 평균 730.5시간/월)
```

#### 월간 비용 계산

**방법 1: 30일 기준 (간단)**
```
월간 비용 = $0.0145/시간 × 720시간
         = $10.44/월
```

**방법 2: 730.5시간 기준 (정확)**
```
월간 비용 = $0.0145/시간 × 730.5시간
         = $10.59/월
```

**평균: $10.50/월**

---

#### 실제 청구 예시 (30일)

```
가격 단계:
• 시간 1-168 (첫 주): $0.0145 × 168 = $2.44
• 시간 169-336 (둘째 주): $0.0145 × 168 = $2.44
• 시간 337-504 (셋째 주): $0.0145 × 168 = $2.44
• 시간 505-672 (넷째 주): $0.0145 × 168 = $2.44
• 시간 673-720 (나머지): $0.0145 × 48 = $0.70
─────────────────────────

```

• 대부분의 스타트업에 충분
